# Getting help

- **Something broken or confusing?** Open an issue on the repository you are using and pick **Report a problem**. For TEAA and TEAA + FRA + Hub that is https://github.com/ToolsEnabled/teaa/issues/new/choose.
- **An idea?** Open an issue and pick **Suggest an improvement**.
- **Your toolsenabled.ai account, sign-in or the hosted service:** email support@toolsenabled.ai.
- **A security problem:** report it privately as described in [SECURITY.md](SECURITY.md), never in a public issue.

Never include passwords, tokens, API keys, cookies or private keys in an issue.
